# Support Copilot — API

Backend на FastAPI. Базовый адрес по умолчанию: `http://127.0.0.1:8000`.
Интерактивная документация (Swagger): `http://127.0.0.1:8000/docs`.

Все примеры ниже получены из настоящего API в режиме `LLM_PROVIDER=disabled`.
Тексты обращений синтетические, тексты правил заменены заглушкой (данные кейса публиковать нельзя).

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/triage` | Разбор одного обращения — основной endpoint |
| `GET` | `/rules?ids=...` | Текст пунктов правил по ID (для показа цитат) |
| `GET` | `/health` | Работает ли сервис и какая LLM включена |

## POST /triage

### Запрос

```json
{
  "kind": "complaint",
  "messages": [
    {"role": "player", "text": "Игрок оскорблял меня, 2.1 ОП", "attachments": 2}
  ]
}
```

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `kind` | `"complaint"` \| `"report"` | да | `complaint` — жалоба из лаунчера, `report` — репорт из игры |
| `messages` | массив, от 1 до 50 | да | Сообщения обращения |
| `messages[].role` | `"player"` \| `"reported_player"` \| `"admin"` | нет, по умолчанию `player` | Анализируется текст `player`; `reported_player` — комментарий обвиняемого (передаётся LLM как контекст) |
| `messages[].text` | строка до 5000 символов | нет, по умолчанию `""` | Текст сообщения |
| `messages[].attachments` | целое 0–100 | нет, по умолчанию `0` | Сколько скриншотов приложено. Содержимое скриншотов сервис не видит |
| `reporter_id` | строка до 128 символов | нет | ID заявителя — нужен для поиска дословных повторов |
| `reported_nick` | строка до 64 символов | нет | Ник обвиняемого (если не передан — ищется в тексте по шаблону `Имя_Фамилия`) |
| `created_at` | дата-время ISO 8601 | нет | Время подачи, по умолчанию — сейчас (для поиска повторов за 24 ч) |
| `server_lang` | `ru` \| `kk` \| `uz` \| `en` \| `es` \| `pt` | нет | Язык сервера — используется, если язык нельзя понять по тексту (например, «+») |

### Ответ 200

```json
{
  "lang": "ru",
  "category": "complaint.insult",
  "priority": "p2",
  "is_spam_or_duplicate": false,
  "extracted": {
    "nickname": null,
    "rule_refs": ["2.1"],
    "has_evidence": true,
    "server": null
  },
  "draft_reply": {
    "lang": "ru",
    "text": "Здравствуйте! Ваше обращение получено и будет рассмотрено администрацией.",
    "cited": ["2.1"]
  },
  "needs_human": true,
  "confidence": 0.7,
  "reasons": [
    "Классифицировано по ключевым словам, LLM не вызывалась",
    "Решение о наказании или действие в игре подтверждает администратор"
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `lang` | `ru` \| `kk` \| `uz` \| `en` \| `es` \| `pt` | Язык обращения. Всегда одно из шести значений |
| `category` | строка | Категория из `taxonomy.json`, всегда соответствует `kind` (`complaint.*` или `report.*`). Список ниже |
| `priority` | `p0` \| `p1` \| `p2` \| `p3` | p0 — критично (взлом, платёж, угрозы), p3 — низкий |
| `is_spam_or_duplicate` | bool | Пустое сообщение без доказательств или дословный повтор того же игрока за 24 ч |
| `extracted.nickname` | строка \| null | Ник обвиняемого |
| `extracted.rule_refs` | массив строк | Пункты правил, которые указал игрок. **Только существующие** в базе правил |
| `extracted.has_evidence` | bool | Есть вложения или ссылка. Это не значит, что нарушение доказано |
| `extracted.server` | строка \| null | Номер сервера, если игрок написал его рядом со словом «сервер» («сервера 18», «25 сервера»); иначе `null` |
| `draft_reply.lang` | как `lang` | Язык черновика — всегда совпадает с `lang` |
| `draft_reply.text` | строка | Черновик ответа игроку. Не содержит обещаний разбана, возврата денег или наказания другого игрока |
| `draft_reply.cited` | массив строк | Цитируемые пункты. **Все проверены программно** по базе правил |
| `needs_human` | bool | `true` — решение должен принять администратор |
| `confidence` | число 0–1 | Уверенность в категории и приоритете |
| `reasons` | массив строк | Объяснение решения для администратора, на русском |

### Формат ID правил

У пунктов разных документов совпадают номера, поэтому у документа есть префикс:

| Пример ID | Документ |
|---|---|
| `2.1` | Общие правила игры (без префикса) |
| `ЖБ 1.1.2` | Правила жалоб |
| `GZ 1.2` | Правила Зелёной Зоны |
| `ОПЛЗ 3.3` | Правила для лидеров и заместителей |
| `ПГО 1.4` | Правила государственных организаций |
| `ПГВД 1.1` | Правила госволны и департамента |
| `FW 1.7.1` | Правила семейных мероприятий |
| `ОПГ 2.1` | Правила для ОПГ |
| `ВБ 1.1` | Правила войны за бизнес |
| `БЗФ 1.1` | Правила битвы за фургон |

### Категории

| Код | Название |
|---|---|
| `complaint.insult` | Оскорбления и токсичность |
| `complaint.cheat` | Читы и стороннее ПО |
| `complaint.dm` | Убийство без повода, нарушение РП, Зелёная Зона |
| `complaint.scam` | Обман и мошенничество |
| `complaint.rmt_ads` | Реклама и продажа за реальные деньги |
| `complaint.admin` | Жалоба на администратора, апелляция на наказание |
| `complaint.other` | Другое нарушение |
| `complaint.invalid` | Не жалоба или без доказательств |
| `report.question` | Вопрос по механике игры |
| `report.help` | Просьба о помощи: застрял, баг |
| `report.complaint` | Жалоба на игрока через репорт |
| `report.account` | Аккаунт: доступ, взлом, пропажа имущества |
| `report.payment` | Платёж и донат |
| `report.offtopic` | Оффтоп, пустые сообщения, просьбы о телепорте |

### Когда `needs_human = true`

Решает код, LLM может только добавить эскалацию, но не отменить её:

- апелляция на наказание, подозрение на взлом, платёж, угрозы вне игры — по словам в тексте;
- категории `report.account`, `report.payment`, `complaint.admin`;
- любое решение о наказании или действие администратора в игре (все жалобы, кроме `complaint.invalid`; `report.help`, `report.complaint`);
- приоритет `p0`;
- уверенность ниже 0.5;
- LLM недоступна и категорию не удалось определить по ключевым словам;
- черновик LLM содержал запрещённое обещание (тогда он заменяется нейтральным шаблоном).

### Частые значения `reasons`

| Текст | Что значит |
|---|---|
| `Классифицировано по ключевым словам, LLM не вызывалась` | Короткое однозначное обращение («оск», «опру», «помогите») |
| `Категория определена по ключевым словам` | LLM недоступна, сработал запасной классификатор |
| `Облачная LLM отключена (LLM_PROVIDER=disabled)` | LLM выключена в `.env` |
| `Квота LLM исчерпана (HTTP 429), попробуйте позже` | Превышен лимит бесплатного тарифа |
| `LLM не ответила вовремя` | Ответ дольше `LLM_TIMEOUT_SECONDS` |
| `Часть цитат LLM отброшена: ...` | LLM процитировала несуществующий пункт — он удалён |
| `Черновик LLM заменён шаблоном: ...` | В черновике было запрещённое обещание |
| `Приоритет p0 понижен до p1: ...` | LLM поставила p0 без признаков взлома, платежа или угроз |
| `Пояснение LLM: ...` | Обоснование от модели — мнение LLM, не решение. Решают правила в коде |
| `Сообщение без содержания и без доказательств` | Спам («+», «.», «53») |
| `Дословный повтор обращения того же игрока за 24 часа` | Дубликат |

### Ещё примеры

Пустой репорт на узбекском сервере — спам, ответ на языке сервера, человек не нужен:

```json
// запрос
{"kind": "report", "messages": [{"role": "player", "text": "+"}], "server_lang": "uz"}
// ответ (сокращён)
{
  "lang": "uz",
  "category": "report.offtopic",
  "priority": "p3",
  "is_spam_or_duplicate": true,
  "draft_reply": {"lang": "uz", "text": "Assalomu alaykum! Iltimos, muammoni batafsil yozing: ...", "cited": []},
  "needs_human": false,
  "confidence": 0.9,
  "reasons": ["Язык не определён по тексту, выбран язык по умолчанию", "Сообщение без содержания и без доказательств"]
}
```

Апелляция («опру» — опровержение наказания):

```json
// запрос
{"kind": "complaint", "messages": [{"role": "player", "text": "опру", "attachments": 1}]}
// ответ (сокращён)
{
  "category": "complaint.admin",
  "priority": "p2",
  "needs_human": true,
  "reasons": [
    "Классифицировано по ключевым словам, LLM не вызывалась",
    "Апелляция на наказание — решает администратор",
    "Категория всегда требует администратора",
    "Решение о наказании или действие в игре подтверждает администратор"
  ]
}
```

### Ошибки

| Код | Когда |
|---|---|
| `422` | Некорректный запрос: нет `kind`, пустой `messages` или больше 50 сообщений, неизвестное значение `kind`/`role`, `attachments` вне 0–100, слишком длинное поле |
| `500` | Не ожидается: ошибки LLM (таймаут, квота, сеть, кривой ответ) **не** приводят к 500 — сервис возвращает безопасный ответ с `needs_human: true` |

Пример 422:

```json
{
  "detail": [
    {"type": "too_short", "loc": ["body", "messages"],
     "msg": "List should have at least 1 item after validation, not 0"}
  ]
}
```

## GET /rules

Текст пунктов правил — чтобы показать администратору, что именно цитирует черновик.
Несуществующие ID молча пропускаются.

```
GET /rules?ids=2.1&ids=GZ%201.2
```

```json
[
  {"id": "2.1", "document": "Общие правила игры", "text": "<текст пункта из rules.json>"},
  {"id": "GZ 1.2", "document": "Правила нахождения в Зелёной Зоне", "text": "<текст пункта из rules.json>"}
]
```

## GET /health

```json
{"status": "ok", "llm_provider": "ollama", "llm_model": "qwen2.5:3b",
 "llm_warning": "Модель qwen2.5:3b не скачана в Ollama: выполните `ollama pull qwen2.5:3b`"}
```

`llm_provider`: `disabled` | `ollama` (с `gemini` сервер не запускается: Gemini Free Tier запрещён для реальных тикетов). `llm_model` — если провайдер включён.
`llm_warning` — только если проверка при старте нашла проблему (сейчас проверяется Ollama: запущена ли и скачана ли модель).

## Примеры вызова

PowerShell (Windows):

```powershell
$body = [System.Text.Encoding]::UTF8.GetBytes('{"kind":"complaint","messages":[{"role":"player","text":"Игрок оскорблял меня, 2.1 ОП","attachments":2}]}')
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/triage -ContentType "application/json; charset=utf-8" -Body $body
```

curl (Linux / macOS):

```bash
curl -X POST http://127.0.0.1:8000/triage \
  -H "Content-Type: application/json" \
  -d '{"kind":"complaint","messages":[{"role":"player","text":"Игрок оскорблял меня, 2.1 ОП","attachments":2}]}'
```

Python:

```python
import httpx

response = httpx.post("http://127.0.0.1:8000/triage", json={
    "kind": "complaint",
    "messages": [{"role": "player", "text": "Игрок оскорблял меня, 2.1 ОП", "attachments": 2}],
}, timeout=30)
print(response.json()["category"])
```

Таймаут клиента — не меньше 10 секунд: с включённой LLM ответ обычно приходит за 1–4 секунды.
