## 5. Что исправлено в финальных итерациях

1. **RAG в основном режиме** — см. раздел 2 (`pipeline._rag_citations`).
2. **Ollama — эксперимент**, только localhost; Gemini — только синтетика (раздел 1).
3. **Приоритеты:** приоритет ответа LLM берётся из правил категории; p0 — только при признаках взлома/платежа/угроз.
4. **Адресат черновика:** ловятся фразы, обвиняющие заявителя; пострадавшему не отвечают шаблоном апелляции;
   без скриншотов и ссылок шаблон не утверждает, что доказательства приложены; апелляция, пришедшая как `report`,
   получает шаблон апелляции.
5. **Выдумки в черновиках LLM:** запрещены утверждения, что нарушение доказано, что наказание ошибочно, что жалоба
   будет отклонена, а также размер наказания; цитата — только названная игроком или пункт итоговой категории.
6. **kk/uz:** язык (казахская кириллица без особых букв, узбекская кириллица с «қ», казахская латиница без диакритики
   на kk-сервере); категории uz по пропускам в train (проверка на valid: апелляции uz 5/10 → 7/10, категория без
   изменений); «банк» больше не путается с «бан».
7. **Безопасность ключа:** `.env.*` в `.gitignore`; ключ в чужой строке `.env` не печатается.

## 6. Известные ограничения

* **Классификация:** 6 апелляций эталона без явных слов уходят в `complaint.other`; 5 коротких жалоб без слов
  получают p2 вместо p3 — сознательно не исправлено: на train такие жалобы одобряются админами в 18% случаев, пометить
  их «без человека» опасно. Дубликатами отмечаются только дословные повторы (0/18 по вердиктам `duplicate`).
* **Эскалация:** человеку уходит 938 из 1000 тикетов valid — по замыслу (решение о наказании принимает админ), но
  разгрузка админов в основном за счёт сортировки, приоритета и черновика, а не автоответа.
* **Цитаты:** RAG-цитата зависит от категории; при неверной категории цитата тоже неверна (85.9% совпадений с вердиктом).
  Для `report.*` и `complaint.other` автоматической цитаты нет.
* **Языки:** казахских жалоб в train 67, в valid 10 — казахские слова не проверены на данных; испанский и португальский
  не измерены (0 тикетов). Транслит «chit/çit» не распознаётся как читы (в train нечем подтвердить).
* **Черновики** — шаблоны на 6 языках: безопасные, но общие (3.72/5).
* **Ollama** на этом ноутбуке хуже основного режима и на границе p95 5 с; CUDA-библиотеки не подхватились (Vulkan).
* **Эталон** мал и размечен AI-ассистентом; черновики оценивал AI-ассистент.
* **История git** содержит 4 короткие цитаты тикетов в старых версиях документации (раздел 7).
* Установка зависимостей в новое чистое окружение не проверялась.

## 8. Команды запуска (Windows, из корня проекта)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# файлы кейса — в папку data/ (rules.json, taxonomy.json, tickets_*.jsonl); .env — копия .env.example (LLM_PROVIDER=disabled)

.\.venv\Scripts\python.exe -m pytest -q                                  # 235 тестов, без сети
.\.venv\Scripts\python.exe -m uvicorn app.main:app                       # API: http://127.0.0.1:8000/docs
.\.venv\Scripts\python.exe -m streamlit run frontend/app.py              # интерфейс: http://localhost:8501
```

Воспроизведение метрик:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.predict --provider disabled --fresh --output outputs/valid.jsonl
.\.venv\Scripts\python.exe -X utf8 -m scripts.evaluate --pred outputs/valid.jsonl      # безопасность, valid, эталон
.\.venv\Scripts\python.exe -X utf8 -m scripts.eval_rag --file data/tickets_valid.jsonl # RAG Recall@k
```
